# Shell Emulator

## 1. Общее описание

Проект **Shell Emulator** представляет собой эмулятор командной оболочки, разработанный на **Python 3** в рамках выполнения практической работы по дисциплине "Конфигурационное управление", **Вариант №25**.

**Реализованные этапы:**

1.  **Этап 1: REPL (Read-Eval-Print Loop)**. Создан минимальный прототип с консольным интерфейсом, простым парсером команд и командами-заглушками.
2.  **Этап 2: Конфигурация**. Добавлена возможность настройки эмулятора через параметры командной строки, включая указание пути к Виртуальной Файловой Системе (VFS) и выполнение команд из стартового скрипта.

---

## 2. Описание функций и настроек

Проект реализован на **Python 3** в файле `shell_emulator.py`.

### **2.1. Реализованные команды (Этап 1)**

В рамках первого этапа реализованы команды в виде заглушек, которые выводят свое имя и полученные аргументы:

* **`ls [аргументы]`**: Команда выводит сообщение о выполнении и переданные аргументы.
* **`cd [путь]`**: Команда выводит сообщение о выполнении и переданные аргументы. Сообщает об ошибке, если не указан путь.
* **`exit`**: Команда завершает работу эмулятора.

### **2.2. Настройки и конфигурация (Этап 2)**

Эмулятор поддерживает передачу параметров при запуске через командную строку, а также выводит отладочную информацию о заданных параметрах.

| Параметр | Тип | Значение по умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| **`--vfs_path`** | `str` | `/tmp/emulator_vfs` | Путь к физическому расположению Виртуальной Файловой Системы (VFS). |
| **`--startup_script`** | `str` | `None` | Путь к файлу стартового скрипта, команды из которого будут выполнены при запуске. |

## 3. Описание команд для запуска проекта и тестов

Проект не требует предварительной сборки.

### **3.1. Запуск эмулятора**

Для запуска используйте `python3 shell_emulator.py` с необходимыми параметрами.

| Режим работы | Команда запуска |
| :--- | :--- |
| **Интерактивный режим (REPL)** | `python3 shell_emulator.py` |
| **Интерактивный режим с VFS** | `python3 shell_emulator.py --vfs_path /path/to/my_vfs` |
| **Режим выполнения скрипта** | `python3 shell_emulator.py --startup_script ./commands.emu` |

### **3.2. Запуск тестов**

Для удобства тестирования реализован скрипт `test_runner.sh`, который проверяет различные режимы работы.

1.  **Создайте тестовый скрипт** `test_script.emu` в корне проекта для проверки режима конфигурации.
